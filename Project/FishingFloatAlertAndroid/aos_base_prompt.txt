@FishingFloatAlertSharp 이 프로젝트의 기능을 @FishingFloatAlertAndroid  여기에 옮길거야.
레이아웃은 이렇게 가져갈 예정임.

- Bottom Navigation Bar로 3개의 메뉴를 만들 예정임. 좌측은 카메라 화면, 중앙은 색상 설정 화면, 우측은 기타 설정 화면
- 각 화면은 아래 설명과 같이 구현할 예정

<중요한 사항>
- [카메라]탭과 [색상 설정]탭의 카메라 영역은 크기를 똑같이 할 것
- 카메라는 1:1 비율을 사용할 것 (Camera2 API)
- 앱은 세로 화면으로 고정할 것 (레이아웃도 세로 화면에 맞춰서 구성)
- [카메라]탭과 [색상 설정]탭의 카메라 뷰를 제외한 버튼 및 기타 UI들은 별도의 영역을 차지하지 않고 카메라 뷰 위에 띄우기
- 카메라 뷰어 크기 조절이 되지 않는다면 카메라 데이터를 가져온 뒤, 중앙 영역을 1:1로 잘라서 화면에 띄우기
- 카메라의 fps는 10fps로 설정가능하다면 설정하고, 10fps가 안된다면 설정 가능한 가장 낮은 fps로 설정하기

[카메라]
- view 영역 전체는 실시간 후면 카메라 화면으로 표시
- 카메라 표시 영역  우측 상단에 예쁜 switch메뉴로 카메라/필터 모드 제공
- 카메라 화면은 실제 카메라 화면을 그대로 노출
- 필터 화면은 opencv를 이용해 특정 색상을 필터링된 상태로 노출
- 카메라 표시 영역 하단 중앙에 camera2 api를 이용해 선택 가능한 모든 배율을 동그란 배경 버튼으로 넣어줌.
- 배율은 1, 2, 3, 5, 10 으로 넣기

[색상 설정]
- view 영역 전체는 실시간 후면 카메라 화면으로 표시
- 화면 하단에 현재 설정 색상을 표시하는 사각형 이미지와 [캡쳐] 버튼,[적용] 버튼 있음
- [캡쳐]버튼을 누르면 카메라가 표시된 현재의 이미지 상태(정지화면)을 표시
- 이후 터치를 통해 현재 설정된 색상을 변경 가능하고, 현재 어디를 선택했는지 십자가로 보여줌. 그 색상은 사각형 이미지에 표시
- 적용을 누르면 십자 이미지는 사라지고, 다시 실시간 카메라 화면으로 돌아옴
- 앱을 껐다 켜도 해당 색상값은 유지 (SharedPrefs에 저장)

[기타 설정]
- 실시간 알람를 켜고 끌 수 있는 스위치 추가 (끌 시 소리 알람이 울리지 않음)
- 색상 허용치를 1~50까지 조절할 수 있는 slider 추가 (PC 앱과 동일)
- PC앱에서는 5픽셀 이하일경우에 알람을 울리게 되어있는데, 해당 값을 1~50 사이에서 조절할 수 있도록 slider 추가. 또한, 현재 화면에 감지된 픽셀의 수를 [카메라]화면 - 필터 모드의 우측 상단에 검정색 배경 + 흰색 글씨로 표시
